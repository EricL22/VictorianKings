# VictorianKings

A mod for Crusader Kings 3 that aims to recreate the politics of the Victorian Era, from the end of the Napoleonic Wars to World War I.

The file vk\_changelist.txt contains an exhaustive documentation of every change made to the mod in its updates up to 0.4.2. After that, please see the commit/release history for the repository.

## How to Contribute
This repository is open to any Github user to create issues, forks, and pull requests. The workflow is as follows:
1. Create an [issue](https://github.com/EricL22/VictorianKings/issues) describing a specific bug you'd like to fix, or a feature you'd like to add. Remember to assign the correct labels for ease of searching.
2. Comment on the issue or notify me through any means that you want to work on the issue, and I'll assign it to you.
3. Fork the repo, and create a new personal branch to implement the issue. My own convention is to use the naming scheme `issue_[issue number]`.
4. Once you have committed to the branch and are satisfied with it, you may create a [pull request](https://github.com/EricL22/VictorianKings/pulls) to the `main` branch and link it to your issue.
5. I will personally review any open pull requests and merge them. I may suggest edits to your PR to make them more in line with the mod's established coding conventions.
